# Directorio Mundial

Directorio mundial de medios y fuentes, con prioridad inicial en **geopolítica** y **medios independientes organizados dentro de cada país**.

## Fase 1
- Continente → región → país/área → medio.
- URL oficial obligatoria.
- RSS opcional.
- Idioma original separado del idioma de lectura.
- Categorías múltiples por fuente.
- Estado de verificación para cada URL.
- Diseño preparado para 20.000+ fuentes.

## Tecnología inicial
- React + Vite.
- Datos estructurados en JSON.
- GitHub Pages.
- Sin Supabase en esta etapa.

## Próximas fases
1. Carga masiva de países y medios.
2. Verificación automática de URLs.
3. Buscador por país, región, idioma, categoría y tipo.
4. Traducción bajo demanda.
5. Ampliación a OSINT, tecnología, IA, ciencia, historia, geografía, deportes, economía, trading, criptomonedas y otros recursos.
